# 完成第 7 课：README 配置说明和警告

学习了配置文件和 README 安全提示中的核心词汇，包括 credential、secret、token、expose、warning 和 production。练习要求回忆词义、解读示例配置并写一段安全的配置说明；练习文本框不保存内容，因此本次按推进请求记录为已完成。

**思考题回答**：
1. **Q1（expose）**：答案是“不要泄露 API token”。`expose` 指把原本应受保护的信息公开或泄露，API token 被暴露后可能被他人冒用。截图、日志、工单和 Git 提交都应避免出现完整 token。
2. **Q2（.env.example）**：答案是“它可展示变量名而不含真实 secret”。示例文件让协作者知道需要配置哪些变量，但应使用占位符而非真实密码或密钥。真实值应只保存在本地或受控的密钥管理系统中。
3. **Q3（warning）**：答案是“先理解风险，再执行相关步骤”。README 的 warning 常说明数据丢失、生产环境影响或敏感信息泄露等后果。忽略警告直接复制命令，往往会把本可避免的风险带入项目。

**Implications**：第 8 课将学习如何用英文请求代码评审，继续以 12 个新词、6 个复习词和场景小测练习真实团队协作表达。
