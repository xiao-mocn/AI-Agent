# 完成第 9 课：回应代码评审意见

学习了接受建议、请求澄清和提出替代方案的英文表达，并掌握 address、clarify、concern、alternative 和 context 等评审回应词。练习要求写 2–3 句 review 回复；练习文本框不保存内容，因此本次按推进请求记录为已完成。

**思考题回答**：
1. **Q1（address）**：答案是“我已处理这条评论”。`address a comment` 表示已对评审意见采取行动或给出回应，不等于 PR 已经被批准或合并。它能让 reviewer 快速知道这条反馈可以重新检查。
2. **Q2（不同意）**：答案是“确认 concern，再说明理由或 alternative”。先认可对方指出的技术风险，能让讨论保持在实现和证据上。之后用 context、reason 或可验证的替代方案说明自己的判断，比直接否定更专业。
3. **Q3（clarify）**：答案是“避免误解评论的具体要求”。评审意见有时只指出现象而未说明完整场景，先澄清可避免在错误假设下修改代码。它不是拖延，而是减少后续 revision 的必要步骤。

**Implications**：第 10 课将学习总结技术讨论并确认下一步，把协作词汇用于会议和异步沟通。
