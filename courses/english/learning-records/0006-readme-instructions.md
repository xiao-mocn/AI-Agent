# 完成第 6 课：读懂 README 的安装指令

学习了 README 安装段落中的核心动作词与名词，包括 clone、install、configure、required 和 optional，并用“动作 → 对象 → 顺序”的方法理解命令说明。练习要求口头回忆词义、复述安装顺序，并写一段简短安装说明；练习文本框不保存内容，因此本次按推进请求记录为已完成。

**思考题回答**：
1. **Q1（optional）**：答案是“这一步可以选择不做”。`optional` 表示该步骤不是项目基本运行的必要条件，通常是附加功能、替代配置或个性化选项。阅读 README 时先完成必需步骤，能避免把注意力花在暂时无关的配置上。
2. **Q2（dependencies）**：答案是“安装项目所需的包”。`dependencies` 是项目运行需要的第三方库或包，`install` 表示把它们下载安装到本地环境。若依赖没有安装，代码即使已经 clone 下来也经常无法启动。
3. **Q3（动作词）**：答案是“它们构成操作主线”。`clone`、`install`、`configure`、`run` 直接说明要执行什么及先后关系，先抓住这些词能快速理解文档骨架。即使还有少数名词不认识，也可以据此开始操作，并在卡住时再查具体词义。

**Implications**：第 7 课将学习 README 中的配置说明和警告，继续以 12 个新词、6 个复习词和场景小测巩固技术词汇。
