# 完成第 2 课：用四句话介绍一个具体项目

学完四个核心句型（项目是什么 / 我的角色 / 用了什么技术 / 遇到并解决了什么问题），练习了用这套结构介绍 AI 聊天后端项目，能把"项目类型 → 职责 → 技术栈 → 挑战与方案"串成一段 30-40 秒内讲完的完整叙述。

**思考题回答**：
1. **Q1（关系代词 that/who/whom）**：答案是 `that`。先行词 project 是物，只能用 that/which 引导定语从句，who/whom 专属指人；that 在口语中比 which 更自然，是介绍项目时的默认选择。
2. **Q2（role was to + 动词原形）**：答案是 `to`。"role was to + 动词原形" 是固定不定式结构，of/for 后面接的是名词或动名词，不能直接加动词原形，这个骨架值得整体记忆。
3. **Q3（so 引导结果状语从句）**：答案是 `so`。"难题 → 所以我做了什么" 是因果顺承关系，so 表结果；because 会把因果说反，but 是转折，都不符合"挑战→解决方案"的叙事逻辑。

**Implications**：第 3 课将把"角色"和"团队协作"结合起来，学习站会（standup）里最常用的进展汇报句型。
