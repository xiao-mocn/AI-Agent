# 完成第 1 课：30 秒技术自我介绍

学完三个核心句型（角色 / 技能背景 / 当前项目），用自己的背景写了一段实战自我介绍："I am a frontend engineer. I have been working with JavaScript, CSS and HTML for two years. Currently, I'm working on an AI chat backend."三个句型都用对了，只有标点（逗号后漏空格、句尾漏句号）和 JavaScript 大小写这类小笔误，不影响整体表达。

**思考题回答**：
1. **Q1（be 动词与主语一致）**：答案是 `am`。"I" 只能搭配 `am`，`is` 专属第三人称单数（he/she/it），`be` 是原形，只在情态动词后（will be）或不定式（to be）里出现，不能直接做主语的谓语。这是母语没有动词变位（比如中文"我是"不需要变形）的学习者最容易踩的第一个坑。
2. **Q2（现在完成进行时）**：答案是 `been`。"have/has been doing" 表示动作从过去持续到现在，正好对应"这项技能我已经用了多久"这种自我介绍里最常见的语义；`have gone` 表示"去了且没回来"，语义完全不对；`have done` 是现在完成简单时，要接动词过去分词而不是 `be doing` 结构，两者不能混用。这个结构在技术面试里出现频率极高，值得当固定搭配背下来。
3. **Q3（介词搭配）**：答案是 `on`。"work on something" 是固定搭配，表示正在做某个项目/任务；"work in" 搭配领域/行业（work in tech）；"work at" 搭配公司/地点（work at Google）。这里没有逻辑可推导，纯粹是搭配记忆问题，直接按整块短语背，避免逐词直译造出中式英语。

**Implications**：第 2 课将在今天三个句型的基础上，扩展到"介绍一个具体项目"（项目背景、你的角色、用到的技术、遇到的问题）。
