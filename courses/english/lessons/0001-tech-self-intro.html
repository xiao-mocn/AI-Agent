第 1 课 · 知识 + 技能

30 秒技术自我介绍

用三个句型，讲清楚"我是谁、我会什么、我在做什么"

为什么从这里开始

技术自我介绍（"Tell me about yourself"）几乎出现在每一场英文面试的开场， 也是加入国际团队、第一次站会自我介绍时最常用到的表达。 它是投入产出比最高的起点：句型固定、场景高频、练熟一次能反复用一辈子。

这节课不讲语法规则，只给你三个可以直接套用的句型， 覆盖"角色 → 技能背景 → 当前项目"这条最自然的介绍逻辑。

三个核心句型

1说明你的角色

I'm a / an ___.

我是一名 ___（角色/职位）

I'm a backend developer.
我是一名后端开发工程师。
2说明你的技能背景

I've been working with ___ for ___.

我用 ___（技术/工具）已经做了 ___（时间）

I've been working with Node.js for two years.
我用 Node.js 已经做了两年。
3说明你当前在做什么

Currently, I'm working on ___.

目前，我在做 ___（项目/任务）

Currently, I'm working on an AI chat backend.
目前，我在做一个 AI 聊天后端。
把三句连起来，就是一段完整、自然的技术自我介绍：
"I'm a backend developer. I've been working with Node.js for two years. Currently, I'm working on an AI chat backend."

词汇小抄

developer 开发者——最通用、最安全的自称，任何场合都合适
engineer 工程师——语气更正式，简历/面试中和 developer 可互换
work on 正在做（某个项目/任务）—— on 不能漏，后面接名词
work with 使用/搭配（某个技术、工具、语言）—— with 不能漏
currently 目前——放句首，提醒对方"接下来说的是现在进行的事"
