读懂 README 的配置说明和警告

先区分“要填什么”和“绝对不能做什么”，再安全地开始配置。

本课目标
  • 记住 12 个配置与安全警告相关的高频词。
  • 复习 6 个 README 安装词。
  • 能读懂一段环境变量说明，并识别敏感信息的安全边界。

本课先背：12 个配置与警告词

点击卡片前先说中文；每张词卡都有一个真实 README 场景。今天不只背词，也要记住它出现时该做什么。

configurationCheck the configuration section.
配置；项目运行所需的设置集合。
credentialNever commit credentials.
凭据，如密码、访问密钥或令牌。
secretKeep the secret private.
密钥、机密配置；不能公开分享。
tokenCreate an API token.
令牌；用于访问 API 的凭据之一。
defaultThe default port is 3000.
默认值；未手动设置时使用的值。
overrideYou can override the default port.
覆盖、改写默认值。
exampleCopy .env.example first.
示例；通常可参考，但不应直接填入真实密钥。
exposeDo not expose your API key.
暴露、泄露（敏感信息）。
sensitiveThis is sensitive information.
敏感的；需要谨慎处理的信息。
warningRead the warning carefully.
警告；提示风险或禁止事项。
productionUse a different key in production.
生产环境；面向真实用户的运行环境。
backupKeep a backup of the file.
备份；重要配置修改前保留的副本。

读配置段落的顺序

README 中常见 .env.example。它告诉你需要哪些变量，但示例值往往不能直接用于生产。先找变量名，再确认要填什么，最后读警告。

# Copy the example file
cp .env.example .env

# Set your own values
API_TOKEN=your_token_here
PORT=3000

# Warning: do not commit the .env file
安全提醒：do not commit 不是语法练习，而是安全约束。真实的 .env 常含 token、password 等 secret；不要把它提交到仓库，也不要在截图、工单或聊天中完整贴出。

两个实用句型

确认默认值

What is the default value for PORT?

PORT 的默认值是什么？

确认安全边界

Should I add this token to the .env file?

我应该把这个 token 写进 .env 文件吗？

轮到你了

步骤 2：看上面的配置块，用中文说出：哪个文件是示例、哪个值需要自己填、哪个文件不能提交。
步骤 3：写一段 3 句英文配置说明，至少使用 4 个新词，并加上一句安全 warning。

不要填写任何真实 token、密码或密钥；练习中一律使用占位符。

本课总结

  • configuration 说明要设置什么；warning 说明哪些操作有风险。
  • credential、secret、token 都属于敏感信息，不能随意暴露或提交。
  • 先看 example 文件理解变量名，再在本地安全地填入真实值。
  • 保留第 6 课的安装词汇，持续用新旧词混合复习。
