读懂 README 的安装指令

抓住动词和关键名词，把“如何开始一个项目”读成可执行的步骤。

本课目标
  • 记住 12 个 README 和安装说明中的高频词。
  • 复习 6 个上一课的排查词汇，建立连续记忆。
  • 能读懂并用中文复述一段简短的安装步骤。

本课先背：12 个 README 高频词

先只看英文词和例句，尝试说中文；点击卡片后再核对。把词放回 README 场景里记，不要把它们当成孤立的单词。

installInstall the dependencies first.
安装；README 中通常指安装依赖或工具。
setupFollow the setup instructions.
设置、初始化配置；也可指整个准备过程。
cloneClone the repository to your computer.
克隆（把远程 Git 仓库复制到本地）。
repository / repoThis repository contains the API.
代码仓库；口语中经常简称 repo。
dependencynpm installs project dependencies.
依赖；项目运行所需要的其他包或库。
packageAdd the package to package.json.
软件包；Node.js 项目里常见。
commandRun this command in your terminal.
命令。
runRun the app locally.
运行、执行；README 里常作动词。
configureConfigure the database connection.
配置；按项目要求设置参数。
environment variableSet the PORT environment variable.
环境变量；放在系统或运行环境中的配置值。
optionalThis step is optional.
可选的，不做也不阻止基本运行。
requiredNode.js 20 is required.
必需的；不满足时通常无法继续。

先识别 README 里的“动作词”

README 的安装段落经常不是完整叙述，而是一串命令和简短指令。先圈出动作词：clone、install、configure、run；再看每一步操作的对象。

# 1. Clone the repository
git clone https://example.com/my-app.git

# 2. Install dependencies
npm install

# 3. Configure environment variables, then run the app
npm run dev
读法：先克隆仓库；然后安装依赖；接着配置环境变量；最后运行应用。你暂时不需要逐个翻译命令，只要能读出“要做什么、先后顺序是什么”。
关键区别：required 是必须满足的前提；optional 是增强功能或替代方式。读 README 时，先完成 required 的步骤，再考虑 optional 内容，能避免把时间花在非必需配置上。

两个读文档的实用句型

确认前提

Is Node.js 20 required for this project?

Node.js 20 是这个项目的必需条件吗？

确认下一步

After I install the dependencies, should I configure the environment variables?

安装依赖后，我需要配置环境变量吗？

本课总结

  • 本课 12 个词覆盖 README 中的仓库、依赖、配置与必需条件。
  • 读安装说明时，先找动作词，再看操作对象和顺序。
  • required 必须优先满足；optional 可以后看。
  • 继续复习上一课的报错词，避免只记住新词。
