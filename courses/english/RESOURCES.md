# 程序员英语 Resources

## Knowledge

- [Tech Interview Handbook: Self Introduction](https://www.techinterviewhandbook.org/self-introduction/)
  高星开源面试准备项目里专门讲技术面试自我介绍怎么组织。用于：面试开场白结构设计。
- [freeCodeCamp: Learn English for Developers (A2)](https://www.freecodecamp.org/news/learn-english-for-developers-a2/)
  freeCodeCamp 官方为非母语程序员设计的免费英语课程，按 CEFR 分级，从入门开始。用于：系统补齐词汇和语法基础。
- [Speak Tech English: 50 Free Resources & Exercises](https://speaktechenglish.com/learn-english-for-software-engineers/)
  专门面向程序员的免费英语资源合集，含真实站会/评审录音和练习。用于：站会、代码评审等团队场景的听力和表达素材。
- [grokenglish.dev](https://grokenglish.dev/)
  专为程序员设计的英语学习站点。用于：技术词汇和常见开发者场景表达。
- Book: _English Grammar in Use_ — Raymond Murphy
  全球最广泛使用的英语语法自学教材，练习驱动、由浅入深。用于：系统补齐语法基础（入门阶段的核心短板）。

## Wisdom (Communities)

- [r/EnglishLearning](https://reddit.com/r/EnglishLearning)
  通用英语学习社区，适合提问具体语法/用词问题。
- [HelloTalk](https://www.hellotalk.com/)
  语言交换 App，可以和母语者做真实口语练习（文字 + 语音）。
- 真实开源项目的 PR / Issue 讨论
  用英语写 issue、参与 code review 讨论，是最贴近"技术面试 + 团队协作"场景的实战场所。

## Gaps

- 还没找到针对"英文技术面试"的高质量免费模拟面试搭子社区（多是付费产品，如 Speak Tech English 的付费课程）。后续可以再找找有没有免费的 mock interview 搭子匹配社区。
