# 方法卡模板

方法卡是帮助学生提取、记忆和跨周迁移已学方法的工具。每个专题完成后生成一张，隔周回顾时学生先独立做题，再用一句话说明方法。

## 卡片结构

```markdown
## 方法卡 X：[方法名称]

**学习周次**：第 X 周

**核心方法**：[用一句话描述，学生能说出的版本]

**回顾题**：[低门槛同结构题，30 秒内能看清关系]

**检验提示**：[估算 / 代回 / 逆推 / 画图，选一个]

**错因警示**：[本专题高频错因码，如 E1/E2/E5]
```

---

## 示例：方法卡 1｜加减巧算

**学习周次**：第 1 周

**核心方法**：找能凑成整十整百的两个数先算，减法要注意符号不能改

**回顾题**：
```
38 + 25 + 62 + 75 = ?
```

**检验提示**：估算接近 200

**错因警示**：E1（把减号当成加号）、E5（不能说出配对理由）

---

## 使用规则

1. **隔周复现**：第 1 周学"加减巧算"，第 3 周课首用方法卡 1 做回顾题
2. **学生先做再说**：不是老师重讲，而是学生独立完成并说出方法
3. **记录三项表现**：结果 / 理由 / 检验，任一项不达标则下周继续复现
4. **方法卡网络**：第 10 周和第 18 周用多张方法卡组合，测试跨专题迁移能力

## 方法卡生成时机

- 每周主专题完成后，在教师笔记中记录"下次生成方法卡 X"
- 在 learning-records/000X.md 中补充"学生能否说出方法"的观察
- 方法卡统一存放在 `reference/method-cards/` 目录下

## 方法卡存档命名

- `method-card-01-addition-subtraction.md`（加减巧算）
- `method-card-02-symbol-placement.md`（巧添符号）
- `method-card-03-equation-puzzle.md`（算式猜谜）
- 依此类推，按学期计划顺序编号
