# 易错点诊断卡

每次连续双课时只选择 1–2 个错因码。记录时写“代码 + 题目来源 + 表现”，例如：`E2｜B 版微练习第 3 题｜把总量当成一份量`。

| 代码 | 错因 | 可观察表现 | 优先修复方式 |
| --- | --- | --- | --- |
| E1 | 运算顺序、括号、漏算 | 先加减后乘除；漏步骤 | 圈运算符、写计算顺序、逐步验算 |
| E2 | 条件遗漏、数量关系 | 看反“多/少/倍”；漏掉条件 | 用线段图或关系表重述题意 |
| E3 | 单位、答语、合理性 | 漏单位；结果明显不合理 | 估算范围 + 完整答语检查 |
| E4 | 图示/表格建模 | 图与题意不对应；不会列关系 | 先标已知/未知，再画最小关系图 |
| E5 | 规律表达 | 只报答案；说不出变化 | 写“每次怎样变”并用一项验证 |
| E6 | 检验 | 不检查；检验与原题无关 | 代回、逆向、估算三选一 |
| E7 | 概念基础 | 不理解余数、倍、平均数等含义 | 用具体情境补最小概念，再回到原题 |

## 三项表现记录

| 项目 | 记录标准 |
| --- | --- |
| 结果 | 正确 / 错误 |
| 理由 | 能独立说明 / 提示后说明 / 不能说明 |
| 检验 | 独立完成 / 提示后完成 / 未完成 |

## 决策规则

- 三项均独立完成：进入下一专题，隔周用方法卡复现。
- 结果正确但理由或检验不足：下周列为易错点复习。
- 结果错误或需要两次以上提示：第 2 节使用低门槛同结构题重建后再测。
- 同一错因连续两周：暂停增加难度，先补概念、图示或基本关系。
