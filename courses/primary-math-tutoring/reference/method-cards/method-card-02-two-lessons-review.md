# 前两课方法卡：加减巧算与巧添符号

## 一、加减巧算：先找整，再选法

1. **换顺序、配一配**：`38 + 25 + 62 + 75 = (38 + 62) + (25 + 75) = 200`。只含加法时可以交换、分组；有减法时连同数字前的符号一起看，如 `357 + 489 - 157 = (357 - 157) + 489 = 689`。
2. **凑整、再补偿**：`269 + 302 = 269 + 300 + 2 = 571`；`473 - 198 = 473 - 200 + 2 = 275`。多减了 2，要加回 2；同理多加了就减回。
3. **连续减法合并**：`300 - 47 - 53 = 300 - (47 + 53) = 200`。减去两个数，等于减去它们的和。
4. **括号先判断**：`374 + (226 - 89) = (374 + 226) - 89 = 511`；`436 - (78 + 136) = (436 - 136) - 78 = 222`。括号前是减号，展开括号时里面各项的符号都要改变。

**口令**：找整百 → 看符号 → 配对或补偿 → 估算验算。换顺序不是随便交换减法中的数字；每一步都要与原式相等。

## 二、巧添符号：先想关系，再写完整

1. **从目标倒想**：目标 24，可以想 `24 = 3 × 8`，再用给出的数凑出 3 和 8。
2. **先定顺序，再添括号**：用 2、2、4、8 各一次：`(2 + 2) × 4 + 8 = 24`。先算 2 + 2，所以括号不能丢。
3. **按题目约束检查**：数字是否用全且只用一次？原题要求顺序不变吗？允许哪些符号和括号？允许拼接数字吗？
4. **按写出的式子重算**：先括号、再乘除、最后加减；同级从左到右。不要按脑中想法计算。

**收尾口令**：数用全、符号全、括号在、按顺序、算回去。
