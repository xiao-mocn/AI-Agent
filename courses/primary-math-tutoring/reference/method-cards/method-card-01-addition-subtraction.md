# 方法卡 1：加减巧算

**学习周次**：第 1 周

**核心方法**：找能凑成整十整百的两个数先算，减法要注意符号不能改

**回顾题 A**：
```
38 + 25 + 62 + 75 = ?
```

**回顾题 B**（连续减法）：
```
300 - 47 - 53 = ?
```

**检验提示**：估算接近整百或用逆向加法验证

**错因警示**：
- E1：把减号当成加号，或改变减数位置后符号错误
- E5：只报答案，说不出"为什么这两个数可以先算"
- E6：不检验，或用与原题无关的方法检验

---

## 教师使用说明

**隔周复现时间**：第 3 周课首 5 分钟

**操作流程**：
1. 出示回顾题 A，学生独立完成（不提示）
2. 学生说出方法：要听到"凑整"或"配对"等关键词
3. 如果 A 题达标，追问 B 题测试连续减法理解
4. 记录三项表现：结果 / 理由 / 检验

**调整规则**：
- 三项均达标 → 本方法卡归档，不再占用课时
- 理由或检验不足 → 第 4 周继续复现
- 结果错误 → 立即用更低门槛题（如 `48 + 52 + 25 + 75`）重建，再隔周测试
