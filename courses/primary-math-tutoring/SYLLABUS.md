# 小学三年级数学辅导教学大纲

## 1. 课程定位

课程服务于校内成绩稳定、思维能力提升和数学表达训练。学生基础较好，因此校内部分不重复基础题，而是用易错点诊断和压轴/拓展题巩固；《举一反三》承担主要的建模、推理和迁移训练。

学校已完成“混合运算与数量关系（一）”与“一天的时间”，当前衔接“两、三位数乘一位数”。学校实际进度优先于本大纲的专题顺序。

## 2. 每周连续双课时结构

每周一次，连续两节课，共 120 分钟。

| 时段 | 时间 | 教学任务 |
| --- | ---: | --- |
| 第 1 节前段 | 24 分钟 | 上次内容的易错点检测、方法卡回顾和针对性订正 |
| 第 1 节后段 | 36 分钟 | 1 道新内容经典例题：展示、静想、建模、关键突破和规范解答 |
| 第 2 节前段 | 42 分钟 | 新内容独立检测、讲评、错因订正和一次迁移检测 |
| 第 2 节后段 | 18 分钟 | 下一校内或思维专题内容的预习，只给情境与预测问题 |

总教学时间中：校内提升与易错复习占 20%，新内容学习与检测占 65%，课末预习占 15%。每周合并 PPT 只安排 1 道主例题；第二节不再引入第二道完整主例题。

## 3. 课堂固定流程

1. **易错点检测**：从上周检测、B 版微练习或校内作业中选 2–3 个短题。
2. **方法卡回顾**：学生先做，再用一句话说明已学方法；不整段重讲。
3. **经典例题学习**：题目展示 → 静想 → 图示/表格建模 → 关键突破 → 规范解答与检验。
4. **新内容检测**：先独立完成，不提供提示。
5. **讲评与迁移**：按错因讲评；用一题短迁移检验是否真正学会。
6. **课末预习**：预热下一内容，不提前系统教学。

## 4. 易错点诊断与调整

使用 [易错点诊断卡](reference/ERROR-DIAGNOSTIC.md) 记录 E1–E7。每周只处理 1–2 类错因，来源优先级为：上次检测 > B 版微练习 > 校内作业。

每道检测题按三项判断：

- 结果正确；
- 能说明关键理由；
- 能独立检验。

| 表现 | 下周决策 |
| --- | --- |
| 三项都达到，且无需提示 | 进入下一专题；隔周方法卡复现 |
| 结果正确，但解释或检验缺失 | 列入下周易错点复习 |
| 结果错误，或需要两次以上提示 | 第 2 节先用低门槛同结构题重建，再测一次 |
| 同一错因连续两周出现 | 暂停叠加难题，回到概念、图示或基本关系 |

## 5. 年度主题路标

| 阶段 | 校内连接 | 思维重点 | 高频错因 |
| --- | --- | --- |
| 运算与规律 | 混合运算、数量关系 | 找规律、巧算、填数、算式猜谜 | E1、E2、E5、E6 |
| 乘法与对应 | 两三位数乘一位数 | 乘法速算、对应、错中求解、列举 | E1、E2、E3 |
| 数据与长度 | 数据整理、长度单位 | 重叠、植树、数字趣谈 | E2、E3、E4 |
| 图形与空间 | 平移、旋转、观察物体 | 数数图形、火柴棒、周长、面积 | E4、E5、E7 |
| 除法与关系 | 两三位数除以一位数 | 有余除法、文字算式、和差、倍数 | E1、E2、E6 |
| 综合应用 | 数量关系分析 | 盈亏、年龄、页码、还原、鸡兔同笼 | E2、E4、E6 |
| 高阶思维 | 校内综合复习 | 平均数、逻辑推理、最佳安排、抽屉原理 | E5、E6、E7 |

36 个专题是资源池，不机械排满。每学期预留 2 个机动周；期末前 2 周进行错题重做、方法卡总复习和校内综合练习。B 版在专题组完成后做阶段测试，测试后先归类错因，再决定是否进入下一组。
