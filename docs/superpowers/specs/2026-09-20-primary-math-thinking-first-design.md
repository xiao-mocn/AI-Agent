# 小学三年级数学辅导：思维提升优先设计

日期：2026-09-20
适用课程：`courses/primary-math-tutoring/`

## 1. 核心决策

本课程是数学思维辅导，不是校内同步补课。学校课本进度只决定短复习题的来源与边界，不决定连续双课时的主专题。

学生已完成第一单元“混合运算与数量关系（一）”和“一天的时间”。下次正式主专题改为《小学奥数举一反三》三年级 A 版的“加减巧算”，再下一次为“巧添符号”。两者都服务于第一单元中已经学过的运算顺序、括号与综合算式，但目标是发现结构、说明理由、进行等值变形和检验，而不是复讲课本算法。

## 2. 专题重组规则

《举一反三》的原书顺序保留为来源索引，但不机械按周次授课：

| 原书专题 | 当前定位 |
| --- | --- |
| 数数图形 | 5–10 分钟有序枚举复习；训练不重不漏与表达 |
| 找找规律 | 后续短热身或独立专题；训练猜想和验证 |
| 加减巧算 | 下次连续双课时主专题 |
| 巧添符号 | 再下一次连续双课时主专题 |

每次 120 分钟只能有一个完整主专题；不把“加减巧算”和“巧添符号”压进同一节课。

## 3. 下次课结构：加减巧算

| 时段 | 时间 | 内容 |
| --- | ---: | --- |
| 复习与热身 | 24 分钟 | 从学校作业抽 1–2 道易错题；数数图形 1 道短题。只复现，不新授。 |
| 主例题 | 36 分钟 | 凑整、交换结合、连续减法改写；先观察可配对的数，再说明等值原因。 |
| 独立检测与迁移 | 42 分钟 | 同结构巧算、带括号变式、说明“为什么可以先算这一组”；按 E1/E5/E6 讲评。 |
| 下次预热 | 18 分钟 | 巧添符号：给数字与目标，收集逆推和凑数的猜想，不讲完整解法。 |

主例题采用《举一反三》第 3 周的凑整思想，不使用未知单价、倍数消元或第二单元乘法作为主例题。建议以 `457 + 321 + 143 + 479` 为入口：先发现 `457 + 143`、`321 + 479` 都能凑整，再用交换律和结合律解释变形合法。
