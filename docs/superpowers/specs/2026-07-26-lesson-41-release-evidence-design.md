# 第 41 课：发布证据与变更记录

## 目标

让学习者把一次真实 Render 发布的版本、非敏感配置变更、探针结果、风险与回滚点整理成可审计的发布记录，使后续排查不依赖个人记忆。

## 教学范围

- 以本次 Render 免费数据库过期、替换数据库并恢复 `/ready` 的事件为案例。
- 区分可记录的发布证据与绝不能写入文档的密钥、连接串、令牌和用户数据。
- 教授发布记录的最小字段：部署标识、时间、变更摘要、验收结果、风险、回滚点与后续事项。
- 在 `docs/releases/` 中创建一份不含敏感信息的 Markdown 发布记录模板与实例。

## 非范围

- 不修改 Render 服务、数据库、环境变量或应用代码。
- 不执行新的业务请求、AI 调用或数据库写入。
- 不将完整日志、连接串、Authorization 头或用户数据复制进发布记录。

## 课程结构

沿用第 40 节的单页 HTML 样式，包含学习目标、理论说明、四步动手实践、验收清单、总结、三道思考题和下一课预告。

1. 说明发布证据服务于复盘和恢复，而不是堆砌日志。
2. 用表格区分版本、探针状态、配置摘要等可记录信息与秘密或用户数据等禁止记录信息。
3. 给出发布记录模板与本次数据库替换事件的安全示例。
4. 让学习者创建 `docs/releases/2026-07-26-render-database-recovery.md`，并以检查命令验证敏感值没有进入文档。
5. 引用 Render 官方文档作为主阅读资源。

## 验收标准

- 创建 `courses/ai-fullstack/lessons/0041-release-evidence-and-change-records.html`。
- 创建 `docs/releases/2026-07-26-render-database-recovery.md`，不包含任何连接串、令牌、密钥或用户数据。
- HTML 包含 `.goal`、四个 `.step`、`.quiz`、Render 官方资料链接和最后一个下一课预告段落。
- 发布记录包含部署标识、变更摘要、探针证据、风险、回滚点和后续事项。
