## Java 迁移基线

迁移目标是保持外部行为、数据边界和可观测契约，不复制 Hono 的目录、函数或中间件组织。Spring Boot 可以使用 Controller、Service、Repository、Filter、Validation 和 Actuator 等本地惯用结构，只要契约和回归证据一致。

### HTTP 路由与响应

| 路由 | 当前外部契约 | Spring Boot 对照要求 |
|---|---|---|
| `GET /` | `200`，JSON 包含服务运行消息 | 保留最小服务标识，不暴露内部配置。 |
| `GET /health` | `200 {"status":"ok"}`，不查询依赖、不要求 JWT | 首个 Java 里程碑必须精确复现状态码与 JSON。 |
| `GET /ready` | 数据库可查时 `200 {"status":"ready"}`；失败时 `503 {"status":"not ready"}` | 将依赖就绪与进程存活分开，失败日志不得泄露连接值。 |
| `POST /register` | 成功 `200 {"ok":true}`；输入错误 `400 {"error":...}`；重名 `409` | 保持校验、密码哈希和冲突语义。 |
| `POST /login` | 成功 `200 {"token":...}`；输入错误 `400`；身份失败 `401` | 保持 JWT 用户标识和有效期约定，避免返回密码字段。 |
| `POST /api/chat` | 需要 JWT；输入错误 `400`；成功返回 SSE `data` 增量和 `[DONE]`；AI 失败 `500` | 保持流式媒体类型、结束标记、错误语义和失败后的数据一致性。 |
| `GET /api/sessions` | 需要 JWT，返回当前用户的 `{sessions:[...]}` | 查询必须按认证用户过滤。 |
| `GET /api/sessions/:id/messages` | 需要 JWT，仅返回当前用户消息并隐藏 `system` 消息 | 保持所有权过滤与 system prompt 保密。 |
| `PATCH /api/sessions/:id` | 需要 JWT；成功 `200 {"ok":true}`；空标题 `400`；不存在或无权 `404` | 保持“不存在或无权”统一为 `404`，修复并覆盖跨域预检。 |
| `DELETE /api/sessions/:id` | 需要 JWT；成功 `200 {"ok":true}`；不存在或无权 `404` | 删除必须带用户条件，并保持消息级联语义。 |

未匹配路由返回 `404 {"error":"接口不存在"}`；未处理异常返回不含内部堆栈的通用 `500` JSON。Java 版本应统一实现相同错误外形，再通过契约测试比较。

### 认证与用户隔离

- `/api/*` 必须接受 `Authorization: Bearer <JWT>`；缺失、无效或过期令牌返回 `401`。
- JWT 至少携带数值型 `userId`，后端从已验证令牌建立安全上下文，不信任请求体中的用户标识。
- 会话列表、消息读取、重命名和删除都必须同时按 `sessionId` 与 `userId` 过滤。
- WebSocket 握手也必须验证用户与会话归属；这是迁移前需要先关闭的当前阻塞，不能把现有缺口复制到 Java。

### 输入与错误契约

- 用户名去除首尾空格，长度 3-30，只允许字母、数字和下划线；密码长度 6-72。
- 聊天消息长度 1-4000，`sessionId` 必须为 UUID；会话标题必须是非空字符串。
- 客户端输入错误使用 `400`，身份失败使用 `401`，资源冲突使用 `409`，不存在或无权访问会话使用 `404`。
- 错误响应保持 `{ "error": "用户可理解的信息" }`，不得返回堆栈、连接信息或凭据。

### 数据模型与一致性

- `users`：数值主键、唯一用户名、密码哈希。
- `sessions`：文本主键、`user_id`、标题、创建和更新时间。
- `messages`：数值主键、`session_id`、`user_id`、角色、内容和创建时间；会话删除时消息级联删除。
- 消息按主键升序恢复上下文，system prompt 持久化但不返回前端；AI 请求失败时不得保留不完整的一轮用户消息。

### 健康检查与日志

- `/health` 只表示进程可响应；`/ready` 必须实际检查数据库并在失败时返回 `503`。
- 每个 HTTP 请求保留请求 ID、方法、路径、状态码和耗时字段；未处理异常日志关联同一请求 ID。
- 日志不得记录 JWT、密码、API Key、完整连接串、system prompt 或真实消息正文。
- 优雅关闭应停止接受新请求，等待后台任务，停止调度与 WebSocket，再关闭数据库连接，并保留超时兜底。

### 回归测试基线

Java 版本至少要复现当前 9 项测试所覆盖的健康、就绪、JWT 拒绝、旧密钥拒绝、会话列表和跨用户删除行为，并补齐本评审发现的缺口：CORS 预检、WebSocket 所有权、消息读取、重命名、输入边界、限流、AI 失败一致性和生产配置。跨语言迁移完成的标准是同一组外部契约测试通过，而不是类名或目录看起来相似。
